# What's new — copy for Partner Center

The **What's new in this version** field, in the four languages the Store listing supports. Kept here
rather than buried in three places in `store-listing.md`, because this is the one part of the listing
that changes on every submission and it is copied out under time pressure.

Each block below is the field's entire contents: copy from the version line to the last bullet.
The Store caps this field at **1,500 characters**; the counts are noted so a rewrite that overruns is
obvious before Partner Center rejects it.

`store-listing.md` remains the source for the description, keywords and everything else.

## English (en)

```
Version 0.7.1

• Fixed: when the app corrected a phrase typed in the wrong layout, a short word or a single letter in the middle of it could be left behind. Those now convert along with the rest. A lone typo is still left as you typed it.
```
